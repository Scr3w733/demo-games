# НЕКРОПОЛЬ: Последний свет

HD‑2D/2.5D пиксельный survivor для Яндекс Игр и ПК: мягкая маска тьмы, радиальные источники света, добавочные свечения (ADD), конус фонарика с батареей, 10 классов, 1028 оружий и 1000 именных уровней кампании.

**Владелец проекта:** `lappyforkyzz@mail.ru`

Вся игра и витрина принадлежат `lappyforkyzz@mail.ru`. Публикация в Яндекс Играх — только под эту почту; регистрацию и подтверждение аккаунта выполняет владелец.

## Быстрый старт

Нужны Node.js 20+ и npm.

```bash
npm install
npm.cmd run build   # Windows/PowerShell: npm.ps1 может быть запрещён политикой выполнения
npm run dev
```

- `npm run dev` — игра: <http://localhost:5173/index.html>, витрина: <http://localhost:5173/landing.html>.
- `npm run build` — `tsc --noEmit && vite build`, результат в `dist/` (входные файлы `index.html` и `landing.html`).
- `npm run preview` — локальный просмотр собранной версии.
- На macOS/Linux вместо `npm.cmd run build` используйте обычный `npm run build`.

## Стек и оформление

- TypeScript + Vite + Canvas 2D, без внешних платных ассетов.
- Логическое разрешение кадра 480×270, вывод на экран в 960×540 без сглаживания.
- Вся графика — процедурический пиксель-арт, весь звук — WebAudio. Внешних mp3-файлов нет.
- Визуальный язык HD‑2D/2.5D: мягкая маска темноты, радиальный свет и ADD-свечения, конус фонарика с расходом батареи, свечи, фонари, жаровни и факелы; детальные здания и интерьеры с мебелью.
- Ориентиры по подаче: Octopath Traveler II, Sea of Stars, Replaced, Eastward. Механики, спрайты и баланс сделаны с нуля.

## Управление

| Действие | Клавиша по умолчанию |
| --- | --- |
| Движение | WASD / стрелки (переназначаются); виртуальный джойстик на тач-экране |
| Прицел | мышь или авто-прицел — режим переключается в разделе «БИНДЫ» |
| Атака | ручной выстрел ЛКМ или `J`; доступен автоогонь |
| Рывок | Пробел |
| Способность 1 / 2 | `Q` / `E` |
| Ультиматум | `R` |
| Аптечка (3 заряда) | `F` |
| Фонарик (батарея) | `T` |
| Взаимодействие: сундук, вход в здание, следующий этаж | `G` |
| Пауза | `Esc` |
| Миникарта | `M` |
| Переход между вкладками меню | клик по вкладке, плавная анимация перехода |

Все бинды — движение, бой, способности, взаимодействие и фонарик — меняются в меню **БИНДЫ**. Там же есть раздел **ГРАФИКА / GRAPHICS**: качество `LOW / MEDIUM / HIGH / ULTRA`, переключатели крови, частиц, освещения, растительности, животных, тряски экрана, размытия движения при беге и новогоднего декора (в декабре включается сам). Раздел **ПРИЦЕЛ / CROSSHAIR** задаёт стиль `КРЕСТ / ТОЧКА / КОЛЬЦО / РУНА / ВЫКЛ`: в бою системный курсор скрыт и вместо него рисуется прицел, в меню остаётся фирменный курсор Некрополя. Язык интерфейса RU/EN выбирается в настройках; меню анимировано, как и заставка загрузки и карточки выбора.

Музыка генерируется процедурно через WebAudio: отдельные сцены для меню, забега, города и босса; громкость и включение хранятся в сохранении. В бою левая плашка показывает HP, броню, шанс крита, активные эффекты состояния (яд/горение/зараза) и быстрые способности. Полный комплект `mod_plating` + `mod_patch` даёт бонус брони и +15% к криту; криты получают отдельный золотой взрыв, звук и тряску.

## Классы и оружие

10 классов:

- Стартовые: **Маг**, **Ниндзя**, **Военный**, **Боксёр**, **Бандит**, **Подрывник** — у каждого три уникальные способности.
- **Вампир** — легендарный класс, лечится от урона.
- **Вампир-Прайм** — мега-легендарный класс, кровь врагов как топливо.
- **Палач** и **Некромант** — мифические классы, тяжёлый топор и проклятия соответственно.

Редкие классы открываются кейсом классов. По 100 видов оружия на класс — **1028 всего** (28 рукодельных и 1000 сгенерированных). У оружия и скинов есть редкость и износ в духе CS, ультрамифический шанс — **0,01%**. Дополнительно работают модули (до 3 одновременно), экипировка и скины.

Звук выстрела собирается из слоёв процедурного WebAudio: у каждого ID оружия и класса своя детерминированная «голосовая» подпись, поэтому 1028 стволов звучат по-разному без единого внешнего аудиофайла.

## Режимы и мир

- **Классический survival** — волны нежити, боссы, смена локаций; есть блиц, кошмар, босс-раш и «Тишина».
- **Кампания** — 1000 именных уровней. Уровень считается пройденным, если вы продержались **60 секунд**; результат и время сохраняются, следующий уровень открывается автоматически.
- **Город: зачистка** — открывается с **5 уровня профиля**, лимит **30 минут**. Мир 8640×6120, 54 здания до **5 этажей** с разными стилями (госпиталь, архив, морг, крипта, мастерская, казарма, башня, склеп), улицы с разбитыми машинами, разрушаемый хлам, сундуки, звёздный рейтинг и масштаб силы врагов; в здания можно входить.
- **Открытый мир** — открывается с **5 уровня профиля**, лимит **60 минут**. Одна карта 14400×10200 с лесами, болотами, руинами, снегом и другими биомами: биом определяется координатами игрока, а не таймером волн. Есть дороги, ориентиры, останки машин, дикие звери, аптеки от состояний и много предметов.
- **База** — убежище с комнатами, порталами, NPC, кузницей, стендом скинов, алтарём, растительностью и животными; улучшения за монеты, телепорт на любой открытый уровень кампании и вход в город. Бонусы базы действуют во всех забегах.
- **Локальная почта** — уведомления о кампании, сундуках и стройке внутри игры. Это не реальная отправка email: для неё потребовался бы сервер.

## Экономика

- Две валюты: монеты и алмазы (`◆`). Монеты и опыт распределяются с пересмотренными, более справедливыми наградами.
- Алмазы сейчас приходят **только из внутриигрового одностороннего обмена монет**: 150 → 1, 700 → 5, 1500 → 12, 3500 → 30. Обратного обмена нет.
- Кейсы: алмазный — 1 `◆`, кейс классов — 3 `◆`, премиальный — 6 `◆`. Премиальный гарантирует эпический предмет или лучше и сохраняет шанс ультра 0,01%.
- **Реальные платежи не подключены.** Алмазная экономика появилась как демо-обмен; донат планируется добавить **после публикации в Яндекс Играх**. Реальная доставка email тоже не работает — почта локальная.

## Дорожная карта движка

Это планы следующих больших систем, а не обещание ближайшего релиза. Сейчас они не реализованы:

- **Строительство** — возведение укрытий, ловушек и укреплений прямо на карте, с сохранением планировки на базе и в забегах.
- **Питомцы** — спутники с разными повадками: защита, поиск предмета, отвлечение врагов, собственные способности и внешний вид.
- **Транспорт** — управляемые повозки/машины для огромных карт, с топливом, столкновениями и боем на ходу.
- **Прокачка и модификаторы оружия** — уровни стволов, прицелы, глушители, магазины, ствольные насадки и редкие сборки с уникальной звуковой подписью.
- **Сезонные события** — ограниченные по времени биомы, задания, боссы и крутые скины для классов и оружия; новогодний декор уже служит первым таким событием.
- **Трассировка лучей** — только после перехода рендера с Canvas 2D на WebGL/WebGPU. Сейчас свет сделан процедурными масками и ADD-бликами; полноценный RT потребует отдельного графического конвейера и проверки производительности.

## Сохранение и прогресс

- Сохранение в `localStorage` под ключом `grimhollow.save.v1` (внутренний ключ, не бренд): рекорды, монеты, алмазы, открытые классы и оружие, скины, модули, бинды, язык, уровень и опыт профиля, кампания, улучшения базы и локальная почта.
- В приватном режиме, где `localStorage` недоступен, игра работает без сохранения.
- Прогресс кампании и рейтинг зданий хранятся в том же сохранении; сетевой синхронизации нет.

## Ассеты и лицензии

- Персонажи, оружие, порталы, деревья и эффекты рисуются кодом (Canvas 2D) в мрачной палитре, звук — WebAudio. Внешних платных моделей и mp3 нет.
- Три CC0-тайл-атласа 0x72 (`DungeonTileset II`, `µFantasy`) дают текстуры пола и дорог, крыши и стены домов, растительность биомов и изображения фонарей — см. `public/assets/LICENSE-CC0.md`. Кадры «рыцарей» из чужих паков убраны: они не подходили по стилю, а оружие снова рисуется только процедурно со сглаженной отдачей.
- HUD над canvas (`z-index: 2`): непрозрачные плашки HP/брони и кнопок способностей с крупными подписями и контрастной рамкой.
- Интерфейс использует **Golos Text** (основной текст) и **Playfair Display** (заголовки) — шрифты с лицензией **SIL Open Font License**. Файлы `public/fonts/GOLOS-TEXT-OFL.txt` и `public/fonts/PLAYFAIR-DISPLAY-OFL.txt` нужно сохранять вместе со шрифтами (`public/fonts/golos-text-*.woff2`, `public/fonts/playfair-display-*.woff2`).
- Проект не является копией существующих игр: перечисленные выше игры — только визуальные ориентиры по подаче HD‑2D.

## Публикация в Яндекс Игры

1. Войти/создать аккаунт Яндекс ID **на `lappyforkyzz@mail.ru`** — регистрацию и подтверждение почты/телефона делает владелец.
2. Открыть [консоль Яндекс Игр](https://games.yandex.ru/console), создать игру и загрузить ZIP из `dist/` как HTML5-билд (входной файл `index.html`, `base: './'` уже настроен).
3. Создать в консоли рекламные блоки и лидерборд и подставить реальные ID вместо заглушек в `src/game/yandex.ts`:
   - `AD.revive` → `revive`;
   - `AD.chest` → `chest`;
   - `AD.interstitial` → `gameover`;
   - `AD.banner` → `menu_banner`;
   - `LEADERBOARD` → `grimhollow_best`.
4. Пересобрать `npm.cmd run build` (Windows) или `npm run build` и загрузить новую версию.
5. Указать имя «НЕКРОПОЛЬ: Последний свет», описание, скриншоты и возврат в витрину.
6. **Заглушка:** `https://yandex.ru/games/app/PLACEHOLDER` в `landing.html` — не рабочая ссылка. После модерации заменить её на реальную ссылку приложения.
7. Опубликовать `landing.html` как статическую страницу (любой хостинг / GitHub Pages / Яндекс.Облако) — витрина собирается вместе с игрой.
8. Не заявлять о работающих платежах или email-рассылке: после публикации планируется только донат, почта остаётся локальной.
